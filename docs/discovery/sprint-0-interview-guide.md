# Sprint 0 switcher interview guide

## Recruitment

Recruit 8–12 prospects to complete at least five interviews, including at least three active WebDiet, Dietbox, or Nutrium users. Keep the external pilot cohort below five practices.

## Session outline

1. Ask the professional to prepare a real follow-up using their current tool.
2. Observe patient creation/import, history review, plan adjustment, publication, and follow-up.
3. Request a de-identified example export; never collect a real patient export during discovery.
4. Ask what would prevent switching even if the new workflow were faster.
5. Test the landing promise and founding-cohort expectations.

## Record

- Current platform and practice size band.
- Time on task and number of context switches.
- Migration blockers and must-retain records.
- Trust, AI-control, privacy, and patient-adoption concerns.
- Willingness to pilot and willingness to pay.
- Evidence that contradicts the current product thesis.

## Import contract gate

Sprint 0 supports a canonical CSV plus a document archive. Before Sprint 1, document required columns, optional columns, normalization rules, duplicate handling, preview behavior, rejected-row reporting, idempotency key, and cancellation before commit.
